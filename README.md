# 遐风观（XiaoTianQi）

一款超级精简、面向国内日常与长辈使用优化的 Android 天气应用（纯 Android SDK 原生开发，零第三方依赖，安装包不到 700 KB）。

## 主要特性

- **极简纯白界面**：纯白底色、无多余装饰，顶部背景色随当前气温变化（越冷越蓝、适宜为绿、越热越红）。
- **醒目当天信息**：顶部正中大字显示当前气温，下方紧挨整天气温、天气状态、风向风速及农历日期。
- **近几日天气预报**：清晰展示今天及未来多日天气与高低温。
- **今日外出劳动建议**：结合温度、降水、风力、湿度与温差自动评估是否适合外出劳动，并给出具体注意事项。
- **默认 TTS 语音播报**：打开应用自动朗读今日气温与劳动建议，顶部可随时暂时关闭/重新开启播报；未检测到中文 TTS 引擎时自动引导安装。
- **中国大陆直连 & 断网多日缓存**：主用腾讯天气国内直连接口（支持县级市如石首市、沅陵县等），GPS 定位先授权、无权限默认展示湖北荆州石首市；本地缓存未来 7 天预报，断网跨天自动对齐到「今天」，数据严重过期时引导打开手机流量更新。
- **独立字体与设置页**：锁定系统「显示大小」与「字体大小」，防止极端系统设置挤压界面；右上角设置页支持独立调节字号、播报语速、查看天气服务商及联系二维码。

## 本地打包

需要 JDK 11+ 与 Android SDK（API 34 & Build-Tools 34.0.0），在 Windows PowerShell 中直接运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build_apk.ps1
```

也可直接用 Android Studio 打开本项目进行构建。
